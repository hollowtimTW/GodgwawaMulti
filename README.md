# Godgwawa Multi

Windows 桌面吉娃娃多隻版（免安裝發行）。

## 下載

請到 [Releases](https://github.com/hollowtimTW/GodgwawaMulti/releases/latest) 下載 `GodgwawaMulti-*-portable.zip`，解壓縮後執行 `GodgwawaMulti.exe`。需要 Windows 及 WebView2。

## 更新

程式會在啟動後檢查最新 Release。發現新版時會詢問是否下載；只有選擇更新才會替換執行檔並重啟。也可在設定的「效能與螢幕」手動檢查。

本倉庫只提供可執行檔及使用說明，不包含工作區中的模型、私有素材或開發原始資料。
